
# Home Credit Project Portfolio

## Overview
This repository contains my work for the Home Credit project. The goal of this project is to solve a business problem for a consumer finance company, involving all the project phases from problem framing to presentation of findings with an emphasis on the business value of the results.

This repository will also serve as a foundation for my professional portfolio.

## Tools & Technologies
* **Environment:** [Positron](https://github.com/posit-dev/positron)
* **Languages:** [e.g., Python / R / SQL]
* **Version Control:** Git & GitHub

## Repository Structure
* `data/`: Contains the raw and processed datasets used for the analysis.
* `scripts/`: Code for data cleaning, exploration, and modeling.
* `README.md`: Project overview and setup instructions.
